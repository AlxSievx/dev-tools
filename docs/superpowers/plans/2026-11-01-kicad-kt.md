# KiCad `kt` + `devtools kicad` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Claude edits KiCad 10 schematics, boards and libraries through Python scripts using a helper library `kt`, run by `devtools kicad run`, checked and pictured by `kicad-cli`.

**Architecture:** `kicad/kt/` is a standard-library package: an S-expression reader/writer that keeps untouched text byte-identical, document wrappers (schematic, board, libraries), and a `Project` that collects changes and saves them in one checked transaction (stage in a temp copy → `kicad-cli` must load it → atomic swap). `devtools/kicad.py` is the CLI; it runs scripts in-process with `kt` and `project` preloaded. No live connection to KiCad.

**Tech Stack:** host Python 3.15 standard library; KiCad 10.0.1 `kicad-cli`; `unittest`.

**Spec:** `docs/superpowers/specs/2026-11-01-kicad-design.md`

## Global Constraints

- Standard library only; nothing is pip-installed or newly installed.
- `kicad-cli` default `C:\Program Files\KiCad\10.0\bin\kicad-cli.exe`; env `DEVTOOLS_KICAD_CLI` overrides. Missing → exit 2, clear message. No fallback, no mock.
- Format versions KiCad 10.0.1 writes (measured 2026-11-01 with `kicad-cli … upgrade`): schematic `20260306`, board `20260206`, footprint `20260206`, symbol library `20251024`. `kt` edits only files with exactly these; others raise `FormatError` naming `devtools kicad upgrade`.
- Untouched nodes are written back byte-identical; a file the script did not change is never written.
- Nothing replaces a project file unless `kicad-cli` loaded the staged copy (load failure = `kicad-cli` exit 3, "Konnte … nicht laden"). Messages from `kicad-cli` are German: read JSON reports and exit codes, never message text.
- Lock file of `X` is `~X.lck` beside it (e.g. `~board.kicad_pcb.lck`) — to be confirmed in Task 12. A locked target → nothing written, exit 6.
- Global library tables (`%APPDATA%\kicad\10.0\fp-lib-table`, `sym-lib-table`) are never written while a KiCad process (`kicad.exe`, `eeschema.exe`, `pcbnew.exe`) runs; `kt` prints the table line instead.
- Exit codes of `devtools kicad`: **0** done · **1** script failed, or rejected by `kicad-cli`, or findings with `--strict` · **2** `kicad-cli` missing / failed to run · **5** usage · **6** a target file is open in KiCad.
- Output capped at 200 lines; full output in `%TEMP%\devtools\kicad\<YYYYmmdd-HHMMSS>-<label>.log`, path printed.
- Pictures are PDF or PNG only (Claude cannot open SVG).
- Tests never touch the user's projects: they build projects in a temp dir or copy stock files from the KiCad install. Tests needing `kicad-cli` skip with "KiCad 10 not found (set DEVTOOLS_KICAD_CLI)" when it is missing.
- Commits: short subject with area prefix (`kicad:` for `kicad/`, `cli:` for `devtools/`, `doc:`, `treewide:`), **no `Co-Authored-By` trailer** (repo rule).
- Run tests: `python -m unittest discover -s tests -v`; one file: `python -m unittest discover -s tests -p "test_kicad_sexpr.py" -v`.

## Review Focus

1. **CRLF files** (Windows git `autocrlf` checks projects out with CRLF): round-trip must keep CRLF, and new nodes use the file's line ending — test in Task 1.
2. **Non-ASCII and escapes** in strings (`"Widerstand 4,7 kΩ"`, `"µC"`, a value containing `"` or `\`): UTF-8 in and out, KiCad escaping — test in Task 1.
3. **Paths with spaces** (project under `Documents\My Boards`): every `kicad-cli` call takes list arguments — test in Task 3.
4. **A script that changes things and then raises**, or changes nothing: nothing written, no mtime touched, no check run — test in Task 4.
5. **Multi-unit symbols** (`Amplifier_Operational:LM358`, units 1–3, `extends "LM2904"`): pins of unit 2 land where KiCad puts them, both units share one reference — test in Task 6.

### Task 1: S-expression core

**Files:**
- Create: `kicad/kt/__init__.py` (empty exports for now), `kicad/kt/sexpr.py`, `tests/_kicad.py`, `tests/test_kicad_sexpr.py`

- Produces:
  - `class Sym(str)` — a bare token (`yes`, `smd`, `roundrect`); plain `str` is a quoted string; `int`/`float` are numbers.

### Task 3: Project, versions, locks, save transaction, new projects

**Files:**
- Create: `kicad/kt/project.py`, `tests/test_kicad_project.py`
- Modify: `kicad/kt/__init__.py` (export `Project`, `new_project`, `FormatError`, `LockedError`, `RejectedError`)

**Interfaces:**
- Produces:
  - `VERSIONS = {"kicad_sch": 20260306, "kicad_pcb": 20260206, "footprint": 20260206, "kicad_symbol_lib": 20251024}`
  - `class FormatError(Exception)`, `class LockedError(Exception)` (`.paths`), `class RejectedError(Exception)` (`.path`, `.output`)
  - `class Document` — `.path: Path`, `.root: Node`, `.changed -> bool` (any node changed, or created new); loads with version check.
  - `class Project(path: str | Path)` — dir (exactly one `.kicad_pro`) or `.kicad_pro`.
    - `.dir`, `.name`, `.pro_path`
    - `.document(path) -> Document` (cached; `Schematic`/`Board`/library wrappers in later tasks subclass `Document` and register themselves by file kind)
    - `.track(doc: Document)` — for documents outside the project dir (private libraries)
    - `.changed() -> list[Document]`
    - `.save() -> SaveResult` — locks → stage → check → swap (`--strict` is the CLI's business, decided from the reports). Raises `LockedError` / `RejectedError`; returns `SaveResult(written: list[Path], reports: dict[Path, Report])`.
  - `locked(path: Path) -> bool`, `lock_path(path: Path) -> Path`
  - `kicad_running() -> bool` (`tasklist /FO CSV /NH`, image names `kicad.exe`, `eeschema.exe`, `pcbnew.exe`)
  - `new_project(dir: Path, name: str) -> Project` — writes `name.kicad_pro` (`{}`), `name.kicad_sch`, `name.kicad_pcb` (the minimal texts from Task 2, uuid4 for the sheet).
  - `Document` subclasses register a checker: `check(staged_path: Path) -> Report | None` (schematic → `cli.erc` on the staged *root* sheet; board → `cli.drc`; libraries → their export, Task 11).
- Consumes: `sexpr`, `cli`.

Save algorithm: (1) changed docs; none → return empty result, touch nothing. (2) any target locked → `LockedError` with all locked paths. (3) copy the project dir to a temp dir, skipping `.git`, `.history`, `*-backups`; write changed in-project docs there; out-of-project docs go to a temp dir of their own. (4) run each doc kind's checker once on the staged copy; `LoadError` → `RejectedError`, nothing written. (5) write each target as `<name>.kt-tmp` beside it, then `os.replace`. (6) return reports.

### Task 4: `devtools kicad` — run, exec, erc, drc, locks, upgrade

**Files:**
- Create: `devtools/kicad.py`, `tests/test_kicad_cmd.py`
- Modify: `devtools/__main__.py` (register `kicad.add_parser(tools)` after fusion)

**Interfaces:**
- Consumes: `Project.save`, errors from Task 3, `cli.erc/drc/run`, `Report.summary`.
- Produces: `add_parser(tools)`; commands below. `kicad/` is put on `sys.path` from `Path(__file__).parents[1] / "kicad"`. Constants `DONE, FAILED, NO_CLI, USAGE, LOCKED = 0, 1, 2, 5, 6`.

| Command | Behaviour |
|--|--|
| `run FILE [--project DIR] [--strict]` | exec the file in a namespace `{kt, project, __file__}`; on exception print the traceback, exit 1, no save; else `project.save()`; print written paths and each report's summary; with `--strict`, any error finding → exit 1 |
| `exec CODE [--project DIR] [--strict]` | same with a string; a trailing expression's repr is printed if not `None` (as Fusion's executor does, `fusion/addin/DevToolsBridge/devtools_bridge/executor.py:44`) |
| `erc [PROJECT]` · `drc [PROJECT]` | report summary; `drc` uses `parity=True` and prints parity findings under their own heading "schematic parity (expected until F8)" |
| `locks [PROJECT]` | every project file that has a lock; nothing → "no files open in KiCad" |
| `upgrade [PROJECT]` | refuse with exit 6 if any file is locked; `sch upgrade --force` / `pcb upgrade --force` each file whose version is not current; print each |

`PROJECT`/`--project` default to the current directory. Errors map: `KicadCliMissing` → 2, `LockedError` → 6 with "close <file> in KiCad (save first)", `RejectedError` → 1 with "rejected by kicad-cli, nothing written" and the cli output's last lines, `FormatError` → 1. Script stdout goes through a writer that tees to the log file and stops echoing after 200 lines.
